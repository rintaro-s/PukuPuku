PukuPuku

かわいいLinux向けタスクマネージャー + ベンチマーク

概要

PukuPuku は Mission Center をベースにしたシステム監視アプリです。CPU・メモリ・ディスク・ネットワーク・GPUの状態を見やすく表示し、ベンチマーク機能も備えています。

※ 本プロジェクトは Mission Center のコードを元に拡張しています（クレジットはリポジトリの README を参照）。

機能

  • CPU / Memory / Disk / Network / GPU のモニタリング
  • かわいいキャラクターによる状態表示（CPUページで表示、サイズ調整可能）
  • CPUベンチマーク、I/Oベンチマーク（CPUのみ実行モードあり）

ビルド

Flatpak（GNOME 49）でのビルド例：

flatpak-builder --user --install --ccache build-flatpak flatpak/io.missioncenter.MissionCenter.json

ビルドが遅い場合は --ccache を付けるとキャッシュが効きます。

設定

設定画面からキャラクターのサイズ（最大800px）を変更できます。
